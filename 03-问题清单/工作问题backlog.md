## 可选的最小问题

- A：一次提问里，`create_agent` 何时发起工具调用？工具结果怎样回到模型？
- B：Agent 中断后，哪些状态能恢复，哪些外部读取可能重做？
- C：完整工具结果与模型可见上下文有什么差别？裁剪后还保留哪些证据？
- D：一次回答不准确，错误来自工具数据、模型推理、业务口径还是证据不足？如何用 3–5 条固定问题复查？
- E：Datus 的一问一答链路与当前 Agent 在上下文、工具或状态上有什么一处重要差异？
- F（Ossie 支线）：Ossie 对语义模型表达提供了什么，哪些正确性仍需 Themis 自行验证？

记录模板：**问题 → 自己的猜测 → 代码/记录/测试证据 → 修正后的解释 → 下一步**。源码结论标版本和位置；未验证的猜测写“待验证”。不把脱离当前目标的 Paimon/Flink/Spark 泛化题目当作待办。
