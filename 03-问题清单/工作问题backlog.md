# 学习问题清单

问题来自应用运行中的真实现象或可复现的合成案例。按[源码 + 应用实践统一路线](../02-路线图/00-总路线图.md)，每条问题都要能用一次运行、一个源码分支和一个边界实验推进；概念疑问可以先记下，但不自动成为独立学习单元。

| 单元 / 项目 | 应用现象与输入 | 我对源码路径的猜测 | 要核对的位置 / 实验 | 证据、结论与状态 |
| --- | --- | --- | --- | --- |
| （学习时填） | | | | |

优先选择这些类型的问题：

- 工具参数合法但业务非法时，是模型、框架还是应用程序拦下？沿 tool call 到 ToolMessage 跑一遍。
- Agent 中断恢复后外部工具是否重做？对照状态记录与实际调用次数。
- 同一个问题在 Datus 中因补充指标口径而改变答案，差异出自上下文选择还是 SQL 执行？
- Paimon 已写入而查询仍读旧值，选择了哪个 snapshot，提交何时可见？
- Flink checkpoint 完成前后故障，状态和外部写入怎样恢复？
- Spark 与实时结果不同，是指标口径、事件时间、snapshot 还是 SQL 计划造成的？

解决后保留问题、固定版本、源码位置、实验结果和曾经错误的猜测。没有亲自核对的实现结论标“待验证”。
