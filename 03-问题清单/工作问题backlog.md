# 学习问题清单

本清单记录按[27 周参考计划](../02-路线图/00-总路线图.md)学习时没弄懂的问题。问题既可来自独立练习，也可来自现有项目；不要求每条都对应工作任务。

一个好问题应能通过小实验、官方资料或一条源码链验证，例如：

- 第 2 周：模型给出 tool call 后，谁真正执行工具？参数非法时在哪一层拒绝？
- 第 6–7 周：并发节点更新同一状态时怎样合并？中断恢复会不会重做外部调用？
- 第 8–9 周：回答变差是检索漏掉证据、上下文被裁剪，还是模型推理错误？
- 第 13–15 周：同一个业务指标被 AI 答错，缺的是表结构、指标口径还是数据验证？
- 第 16–27 周：实时值与批查询值不同，差异来自事件时间、snapshot 还是 SQL 口径？

解决后保留问题和证据；未验证的结论标“待验证”。以前列出的泛化工作题仅作选题灵感，不再自动排入学习计划。
