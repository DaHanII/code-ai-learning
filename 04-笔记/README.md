每完成一个单元，用[笔记模板](../01-方法论/笔记模板.md)写一页，至少记录：

- **问题与预测**：要解释哪个应用行为，原先认为源码会怎么处理。
- **运行证据**：输入、预期、实际、日志/trace、版本；未运行的部分明确标注。
- **源码证据**：从实际入口到关键分支，亲自核对位置；没有依据的结论标“待验证”。
- **边界实验与决策**：改变一个输入或条件后发生什么，这会怎样影响应用设计或排障。
