# AI 辅助读源码

目标：用 AI 把「读开源项目」变成一条可执行、可验证、能回填工作的流水线，而不是让 AI 替你概括仓库。

先用 3 周把 LangChain / LangGraph 从「会用」补到「会造」，再依次拿下四个仓库：Datus、Apache Paimon、Apache Flink、Apache Spark。原源码主线约 17 周。新增「数据建模与 Ossie」4 周专题，推荐在 Datus 后串行学习，合计约 21 周；专题每周约 6 小时，详见学习路线。

## 三条基本原则

1. **问题驱动，不追求读完。** 每个仓库的入口都是工作里一个真实问题（慢、错、不稳定、不满足需求），带着问题读到的代码才留得住。
2. **AI 负责「导航 + 解释 + 出题」，你负责「验证 + 复述 + 下结论」。** 任何未经 文件:行号 核对的 AI 结论一律不进笔记。
3. **读完必须留下三样东西：** 一条画得出来的链路、一篇能给别人讲的笔记、一个跑得起来的最小实验。

## 最小启动动作（今天就能做）

1. 打开 `Langchain1.0-Langgraph1.0-Learning-main`，按 `00-前置-LangChain-LangGraph巩固路线.md` 做第 1 周的主动回忆练习——关掉文档，从空白文件重写 3 个 phase1 练习。
2. 克隆 Datus 仓库并锁定版本（`v0.4.3`，见 `02-路线图/00-版本锁定.md`）。
3. 在 Datus 仓库根目录启动 Claude Code / Cursor，用提示词库 P1 生成一份 `CLAUDE.md` 仓库地图。
4. 从 `03-问题清单` 挑第一个问题，按 `01-Datus源码阅读路线.md` 的 Stage 1 走。
