# AI 辅助读源码与应用实践

这个项目的主线是**用应用问题牵引源码阅读，再用源码和实验改进应用**。沿 LangChain/LangGraph → Datus → Paimon → Flink → Spark，始终复用一个小型数据问答场景。每个学习单元都要留下运行现象、亲自核对的源码位置、边界实验和一条设计或排障结论。

**执行入口：[源码 + 应用实践统一路线](02-路线图/00-总路线图.md)。** 十六个单元表示顺序，不绑定日期；已有工作成果能满足验收时直接复用。概念资料按问题补，不把知识点清单当进度。

## 从哪里开始

先按[第一周学习单](阶段/阶段一/07-第一周-模型调用与结构化输出.md)完成咕泡 S01/S02 的模型调用与参数抽取：运行正常与歧义输入，保存原始响应和程序校验结果；接着在固定版本的 LangChain 源码中追这次调用的关键路径，制造一次非法输入并复跑，写一页[笔记](01-方法论/笔记模板.md)。不需要先完成一套课程。
