# AI 辅助读源码：系统提升路线

主线是 **LLM 与 Agent 能力**：模型调用、结构化输出、工具、检索、LangChain/LangGraph、上下文工程、评估与可靠性，再到数据 Agent。语义建模与 Ossie 作为 AI 数据问答的支撑；Paimon、Flink、Spark 安排在后段，建立未来需要的数据系统基础。

**执行入口：[27 周学习目标参考版](02-路线图/00-总路线图.md)。** 周次表示学习顺序，不绑定日期；每周约 4–5 小时，按实际节奏顺延。现有项目和教程可提供练习素材，不决定知识顺序；工作成果满足当周验收时直接复用。

## 从哪里开始

第 1 周直接用 LangChain ChatModel 完成一次结构化信息抽取：观察消息、流式输出、原始响应与用量，并验证正常、缺字段、歧义三种输入。第 2 周在同一个助手中加入工具调用。每周的具体目标、最小练习与过关标准都在总计划中。
